# ThreadScope Logo Exploration

本轮以产品现有的黑白、Vercel/Geist 风格为基线，围绕三个品牌概念展开：

- **Thread**：连续的会话轨迹、Turn 与工具调用。
- **Scope**：观察窗口、聚焦与上下文边界。
- **Trace**：实时状态、分支关系与可追溯性。

## 六个方向

1. **Scope Thread（推荐）**：断开的观察环中穿过一条实时轨迹；产品含义最完整，16px 下仍有明确轮廓。
2. **Turn Stack**：三条 Turn 被同一个观察窗口截取；更偏数据工具和时间线。
3. **Trace Lens**：放大镜与 trace 合体；含义直接，但更接近通用“搜索/观察”符号。
4. **Scope Brackets**：代码括号包围一次聚焦事件；开发者气质最强。
5. **Thread Topology**：一个 Thread 分出多个 Turn/节点；更偏关系图与 agent orchestration。
6. **TS Monogram**：由单条路径构成 T/S 字母；品牌性强，但产品语义最隐性。

所有 SVG 使用 `viewBox="0 0 100 100"` 与 `currentColor`，可直接跟随浅色/深色主题。`showcase.html` 可用于对比完整尺寸、32px、16px、反色与应用栏场景。
