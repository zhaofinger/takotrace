# ThreadScope ImageGen Logo v2

- Mode: built-in `image_gen`
- Use case: `logo-brand`
- Selected concept: Two-layer thread
- Background: genuine transparent alpha

## Final prompt

```text
Use case: logo-brand
Asset type: final production logo concept and 16px favicon for ThreadScope
Primary request: create one ultra-simple original symbol made from exactly two thick offset horizontal slabs inside an implied square; carve one continuous white vertical thread through both slabs with exactly one gentle bend, so the negative-space thread visually connects the two execution layers
Style/medium: flat vector-like logo, strict modern developer-tool identity, bold and restrained
Composition/framing: centered compact square silhouette, generous transparent margin, front-facing flat 2D geometry, no perspective
Color palette: pure solid black only
Constraints: genuinely transparent alpha background, not a visible checkerboard; exactly two black masses and one white negative-space path; large simple geometry that remains crisp and recognizable at 16px; rounded outer corners; no text, letters, words, watermark, outlines, gradients, shadows, glow, texture, mockup, or antialiased decorative detail
Avoid: database cylinder, server stack details, arrows, circles, rings, targets, eyes, lenses, Git branching icon, chat bubbles, AI stars, infinity loop, Vercel triangle
```

## Meaning

上下两层代表 Thread 中连续发生的 Turn 与执行层；中间的负空间是一条贯穿上下文的可追溯路径。四块实体同时构成一个紧凑的观察窗口，适合现有黑白、Geist 风格界面。
