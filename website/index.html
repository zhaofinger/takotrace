在你的电脑上运行

连接本机的 Codex 与 Claude Code，登录仍由它们处理。TakoTrace 不增加遥测或远程会话存储。

开始使用

需要 Node.js 22+，并已安装 Codex 或 Claude Code。在终端运行这条命令，浏览器会自动打开。

阅读完整文档 ↗
启动命令
$npx takotrace

本地 API 没有通用认证层，请勿直接暴露到局域网或公网。
